# 공간라운지 USP — 누구의 · 어떤 문제를 · 얼마나 쉽게 + 점검 (2026-10-01)

> 공간마켓 USP(`docs/USP-2026-10-01.md`)와 같은 방식. **지금 실제로 되는 것만**(근거 코드 칸).
> 결정 유지: 라운지는 **대화 우선** — 광고형 견적 CTA 를 두지 않는다(Lounge CTA Simplification · `lib/loungeToRequest` 머리말).

---

## 0. 한 문장

**집·동네 이야기를 실명 부담 없이 묻고, 같은 동네의 실제 시공 사례와 업체의 답을 보며, 필요하면 바로 견적으로 넘어가는 곳.**
업체에게는 **광고 대신 «답»으로 실력을 보여 주는 곳.**

## 1. 누구 (타깃)

| | 누구 | 상황 |
|---|---|---|
| **고민하는 사람** | 집을 고칠지 말지·얼마인지 고민 중인 사람 | 견적이 적정한지, 이 공사가 필요한지 물어볼 데가 없다 |
| **동네 사람** | 같은 동네 생활·집 이야기를 나누고 싶은 사람 | 실명·지인 눈치가 부담이다 |
| **업체** | 동네 인테리어 사장님 | 광고비 없이 신뢰를 쌓고 싶다 |

## 2. 어떤 문제

① 인테리어 정보가 광고와 섞여 있다 · ② 실명으로 묻기 부담 · ③ «내 견적 적정한가»를 물을 곳이 없다 · ④ 우리 동네 **실제 사례**를 보기 어렵다 ·
⑤ 물어본 뒤 견적까지 멀다 · ⑥ 업체는 실력을 보여 줄 자리가 없다 · ⑦ 새 글·좋은 글을 놓친다

## 4. 점검 — 약한 곳 (✅ 좋음 · 🟡 약함 · 🔴 위험)

| | 무엇 | 판단 | 왜 · 제안 |
|---|---|---|---|
| A | **익명 + 운영 글 «운영» 배지** | ✅ | 사람 글인 척하지 않는다(6) · 실명 부담 없음(1). 그대로 |
| B | **업체 답변에 연락처 없음** | ✅ | 미니 포트폴리오만 · 대화 신청은 일반 사용자끼리. 입찰 전 업체 연결 금지(대표 09-30)와 같은 방향 |
| C | **카테고리 20개 중 14개가 생활**(연애·주식·취업·여행·맛집·유머…) | 🟡 | 사람이 적을 때 빈 칸이 많아 «죽은 곳»처럼 보이고, «공간»라운지 정체성이 흐려진다. **제안**: 공간 이야기 6개를 앞에 · 글 0개인 생활 칸은 탭에서 접기(지우지 않음). 대표 결정 |
| D | **운영(자동) 글 비중** | 🟡 | 정직하게 표시돼 있지만, 사람 글이 적으면 목록이 «운영»으로 가득 찬다. **지금 비율을 모른다** → 관리자 숫자로 보자(5절) |
| E | **라운지 → 견적 전환** | 🟡 | 길은 있다(4 · 작은 링크 — 일부러 작게). 그런데 **몇 명이 넘어가는지 기록이 없다** → USP 표에 줄 추가(5절) |
| F | **업체 참여** | 🟡 | 전문가 답변·글이 **몇 개인지 모른다**. 업체가 0곳에 가까운 지금은 5·3번이 빈 채로 보일 수 있다 |
| G | 대화 신청 토큰(20) | ✅ | 수락 때만 차감 · 모자라면 미리 안내 — 헛수고 없음 |

## 5. 다음 — 측정부터 (공간마켓 USP 표와 같은 방식 · 대표 「해」 뒤)

관리자 «USP 12 · 사용 → 전환»(187) 옆에 **라운지 줄 3개**:
1. **라운지 → 견적**: «견적 요청서 미리 채우기» 링크를 누른 사람(앱 기록) → 3일 안 요청
2. **사람 글 비율**: 기간 안 라운지 글 중 사람 글(`is_seed = false`) %
3. **업체 참여**: 업체 글(`is_expert`)·업체 답변(`is_expert_reply`) 수 → 그 글을 본 사람의 미니 포트폴리오 열기

> 숫자가 생기면 C(카테고리 접기)·D(운영 글 줄이기)를 숫자로 정한다 — 감으로 정하지 않는다.
