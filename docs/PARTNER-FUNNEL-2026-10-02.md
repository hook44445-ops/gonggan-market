# 업체 가입 깔때기 점검 (2026-10-02)

> 대표: «1(영업지역 점검), 3(업체 모으기 도구 점검)». 지역 조회 SQL 결과 0행 → 업체가 아직 없거나 지역이 빠지는가부터.
> 코드를 읽고 고쳤다. 숫자는 지어내지 않는다 — 실제 숫자는 관리자 «숫자 보기 → 업체 가입 깔때기».

## 1. 영업지역 — 문제 없음

| 자리 | 확인 |
|---|---|
| 업체 가입 2단계(`CompanyOnboarding`) | 영업지역 **필수**(최대 2곳) · `region`(대표 지역 글자) + `service_regions` 둘 다 저장 |
| 옛 가입상담(partner_leads) 경로(`MainApp`) | 로그인한 사용자 지역(`user.region`)으로 저장 |
| 고객 요청의 지역 | 고객 가입 때 고른 지역(`users.region`)이 요청 `area` 가 된다 |
| 새 요청 알림(110) · 월요일 동네 알림(171) | 요청 지역의 마지막 낱말(예: «중원구»)이 업체 `region`/`service_regions` 글자에 들어 있으면 보낸다 |

→ 지역 조회 0행은 **지역 누락이 아니라, 테스트 업체 말고는 업체가 아직 없다**는 뜻으로 본다.

## 2. 깔때기 — 고친 것

| 단계 | 문제 | 고침 |
|---|---|---|
| 입점 페이지 → «입점» 클릭 | GA(gtag)로만 보냈는데 **GA 가 설치돼 있지 않아 아무 데도 안 남았다** | `activity_logs` 에 남긴다(`lib/partnerFunnel` · 같은 창에서 한 번) |
| 가입 3단계 중간 이탈 | «가입 마치기» 전엔 서버에 아무것도 없어 **어디서 그만두는지 안 보였다** | 2단계(지역) · 3단계(공종) 도착을 남긴다 |
| 가입 마친 화면 | «지금부터 우리 동네 견적 요청을 보고 **입찰할 수 있어요**» — 바로 아래 카드는 «입찰 잠김»(124 이후 사실 아님) | «요청을 볼 수 있어요 · 입찰은 사업자등록증 확인 뒤» + **«사업자등록증 올리기»** 버튼(서류 화면으로 바로) · «먼저 동네 요청 둘러보기» |
| 관리자 승인 알림 | «이제 견적 요청을 받을 수 있습니다» — 이미 보이던 것이라 **무엇이 열렸는지 모름** | «사업자등록이 확인됐어요 — 입찰이 열렸어요 · 공사 1건 500만원까지 · 시공보험이면 1,000만원» |
| 새 요청 알림(110) | 확인 전 업체: 예산 미정 요청은 «**바로 입찰할 수 있어요**»(거짓) · 예산 있는 요청은 «한도 밖 · 지금 한도 0만원» | SQL 203: «우리 동네 새 견적 요청 — 사업자등록증을 올리면 입찰할 수 있어요(홈택스 당일 발급)» · 하루 한 번 |
| 월요일 동네 알림(171) | 확인 전 업체에게 «지금 먼저 견적을 보내 보세요»(보낼 수 없음) | SQL 203: «아직 열린 요청이 K건 · 사업자등록증을 올리면 입찰할 수 있어요» |

## 3. 관리자 «업체 가입 깔때기»

`숫자 보기` 안 · 7/14/30일:
1 입점 페이지 봄 → 2 입점 버튼 누름 → 3 가입 2단계(지역) → 4 가입 3단계(공종) — **기록(10-02 배포부터)**
→ 5 가입 마침(업체 생성) → 6 사업자 확인됨 → 7 입찰한 업체 — **실제 표**(테스트 업체 제외)
· 앞 단계 대비 % · 가장 많이 빠지는 곳 한 줄(앞 단계 5 미만이면 말하지 않음) · 가입 화면에서 바로 «사업자등록증 올리기» 누른 수

## 4. 남은 것

- 업체 페이지에서 온 요청 알림(`MainApp` · «바로 입찰할 수 있어요»)도 확인 전 업체에게 갈 수 있다 — 대표가 고른 범위 밖(2번)이라 남김.
- 실제로 업체를 데려오는 일(지인 · 동네 업체 10곳)은 코드 밖 — 깔때기 숫자는 «데려온 뒤 어디서 빠지는지»를 보여 준다.
