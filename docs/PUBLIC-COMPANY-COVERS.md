# 업체 공개 페이지 기본 그림

2026-09-28 · `/p/:ref` 공개 화면에만 적용.

- 첫 공종으로 6종 커버를 고른다. 업체 고유 `cover`가 있으면 우선한다.
- 화이트 욕실, 화이트·우드 주방, 내추럴 우드 도어, 화이트 마감, 초록 집수리, 모던 뉴트럴 거실.
- 기본 커버는 «분위기 그림»으로 표시한다. 실제 시공 사례 데이터에 AI 그림을 넣지 않는다.
- 사례와 후기 0건 안내는 공개 화면에서만 노출한다. 앱 안 업체 화면은 기존대로 유지한다.
- 카카오 등 공유 미리보기는 실제 시공 사진 우선, 없으면 공종 커버. 기본 그림을 구조화 데이터의 시공 사진으로 등록하지 않는다.
- 업체 업로드 커버·로고·소개 및 SQL 변경은 이번 범위에 없다.
