## 4. 방법 · 함정 (이번 창에서 새로 배운 것 — 3차 5장에 더해)

- **내부 브라우저는 창을 새로 열 때마다 기기 인증이 풀린다** → 로그인(번호·인증번호)은 대표. 한 번 들어오면 세 역할 모두 문자 없이 전환된다.
- **대표와 같은 창을 동시에 누르지 않는다** — 대표가 로그인하는 사이 Claude 가 누르면 역할이 섞여 보인다(버그 아님). 「지금부터 제가 조작합니다」라고 말하고 시작.
- 역할 전환(페이지를 새로 불러오면 다시 정의):
  ```js
  const sleep=ms=>new Promise(r=>setTimeout(r,ms));const btn=t=>[...document.querySelectorAll('button')].find(x=>x.innerText.trim()===t);
  window.__switch=async(role)=>{const nav=btn('마이')||btn('내정보');nav?.click();await sleep(2000);
    const l=[...document.querySelectorAll('button,div,span')].reverse().find(x=>x.innerText&&x.innerText.trim()==='로그아웃');l?.click();await sleep(2500);
    [...document.querySelectorAll('button')].find(x=>x.innerText.includes('무료 비교견적 받기'))?.click();await sleep(2000);
    const c=[...document.querySelectorAll('button')].find(x=>x.innerText.includes(role)&&x.innerText.includes('6030'));c?.click();await sleep(4000);return [!!l,!!c];};
  // 사용: await window.__switch('업체' | '의뢰인' | '관리자')
  ```
  업체로 들어가면 파트너센터가 먼저 뜬다(← 로 업체 홈). 공사 화면에서는 ← 를 두세 번 눌러 하단 탭이 보이게 한 뒤 전환.
- 약관 동의 창이 뜨면 **매번 대표 허락**(「동의 눌러도 될까요?」).
- 입력칸 채우기: React 입력은 `Object.getOwnPropertyDescriptor(HTMLInputElement.prototype,'value').set.call(el,v)` + `input` 이벤트.
- 콘솔 요청 기록은 250개에서 꽉 찬다 → 페이지 열 때마다 `performance.setResourceTimingBufferSize(5000)`.
- **운영에 없던 칸이 또 있었다**: `users.space_temp`(114 로 추가). SQL `language sql` 함수는 만들 때 칸을 검사하므로 42703 이 줄 번호와 함께 난다 — 대표가 말한 줄 번호로 바로 찾는다.
- 토스 sandbox 401 은 `px-payment-parameters?Authorization=Basic…` 요청으로 보인다(base64 앞부분으로 어떤 키인지 확인 가능 — 클라이언트 키는 공개값).
- 방(`고객ID_업체ID`)은 같은 고객·업체의 공사를 모두 담는다 — 공사 구분은 C33 구분선, 카드는 가장 최근 공사.
