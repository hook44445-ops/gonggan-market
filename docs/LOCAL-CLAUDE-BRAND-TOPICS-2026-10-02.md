## 1. 무엇을 만드나

### 1-1. 공간마켓 USP 글 (주 2편)

- 사실 출처는 **`docs/USP-2026-10-02.md`(최신판) 3절(USP 12)** 만. 4절(«아직 USP 로 말하면 안 되는 것»)은 쓰지 않는다.
- **안전결제는 `PAYMENTS_LIVE` 전이라 약속 금지**, 고객용 글에 «에스크로» 단어 금지.
- 형식은 «광고»가 아니라 **문제 → 해결 이야기**(도움이 되는 글). 예시 주제(한 USP = 한 글):
  - «견적 3곳, 왜 금액이 다 다를까 — 같은 조건으로 받는 법»(USP 2·3)
  - «우리 동네 평당 시세, 어디서 보나»(USP 4)
  - «추가금 안 붙게 — 최종 견적서에 꼭 있어야 할 3가지»(USP 7)
  - «공사 끝나고 하자보수 기간 놓치지 않기»(USP 8)
  - 업체용: «가입비 없이 동네 견적 받는 법»(USP 9) · «떨어진 견적, 다음엔 뭘 고칠까»(USP 10) · «증빙 하나씩 — 맡을 수 있는 공사 금액 한도»(USP 11)
- 글 끝에 **할 일 한 줄**(«30초 요청서 써 보기» 같은 앱 안 링크) — 과장 · 1등 · 최저가 표현 금지.

## 2. 어디에 붙이나 (코드)

- `src/lib/serverAutonomousCycle.js` — `runAutonomousCycle` 의 생성 단계(트렌드 → `filterNewTopics` → `writeLoungePost` / `composeCategoryPost`) 옆에 **«편성표 단계»** 하나:
  - 새 순수 모듈 `src/lib/brandProgram.js`(가칭): 오늘 날짜(KST) → 오늘 쓸 주제 0~1개(요일 · 계절 달력 · USP 순번). DB/API 없음 · 테스트 쉬움.
  - 표시 `ai_source = 'server_brand'`(USP·프루비) · `'server_topic'`(달력 주제). 기존 자동 승인 필터(122행 `in.(server_llm,server_template)`)에 **넣지 않는다** → **초안으로만** 쌓이고 관리자가 «AI 글 공장»에서 보고 올린다(처음 한 달). 대표가 «자동으로 올려»라고 하면 그때 `server_topic` 만 필터에 더한다. `server_brand` 는 계속 사람 확인.
  - 서버 AI 키가 없으면(`llmWriterConfigured()` false) 이 단계는 **건너뛴다**(틀 글로 브랜드 글을 만들지 않는다).
- **새 서버 함수 금지(12/12)** — 기존 자율 사이클 안에서만.
- 관리자 «AI 글 공장» 초안 목록에 `server_brand` / `server_topic` 표시(«브랜드» · «주제 편성» 칩)만 더한다.
- 새 테스트 파일은 `package.json` test 목록 **맨 앞**.

## 3. 알림 — 광고 규칙 (중요)

- 지금 139 트리거(`enqueue_lounge_post_push`)는 **공개된 라운지 글마다** 푸시를 큐에 넣는다(분류가 안 맞으면 «라운지에 새 글이 올라왔어요»).
- 브랜드 글(`server_brand`)은 **광고성** → 일반 «새 글» 푸시로 나가면 안 된다.
  - SQL(앱 먼저 → SQL 나중): `enqueue_lounge_post_push` 맨 위에 `if v_post.ai_source = 'server_brand' then return 0; end if;` (칸이 없을 때를 대비해 `to_jsonb(v_post) ->> 'ai_source'` 로 읽기) · 확인 칸 1개.
  - 브랜드 글을 알림으로 보내려면 따로: **광고 동의자만 · 제목 앞 «(광고)» · 9~20시 · 수신거부 안내** — 이번 작업 범위 아님.
- SQL 은 파일로 만들고 대표에게 «전체 원문 + 확인 칸 수 + 먼저 할 것 + 실행 뒤 폰 확인»으로.
