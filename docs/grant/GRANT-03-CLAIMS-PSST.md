# 정부지원사업 주장·PSST — 공개 요약

갱신: 2026-09-29. 현재 단계는 공개 베타 MVP이며 운영 접근제어 보강과 실증을 진행 중이다.

| 구분 | 표현 범위 |
|---|---|
| CAN_SAY | 견적부터 후기까지 프로젝트 이력을 연결하는 코드 기반을 구현하고 공개 베타를 배포했다. |
| NEEDS_EVIDENCE | 운영 사용자 흐름, 접근제어 검증, PG·실결제, 데이터 축적량·품질, 분쟁 감소 효과. |
| CANNOT_SAY | 보안 감사 통과, 접근제어 보강 완료, 위변조 불가, 완전 안전, 실제 안전결제 제공 중, AI 성능 검증 완료. |

## PSST

- P: 견적 기준의 차이, 구두 합의와 분산된 공사 기록을 문제 가설로 설정한다. 외부 통계는 출처 확인 전 수치로 쓰지 않는다.
- S(Solution): 견적·서류 검토·현장 기록·계약 기록·단계 승인·후기를 연결하는 MVP를 구현했다. 실제 운영 효과는 별도 검증한다.
- S(Scale-up): 접근제어 보강과 실증, 데이터 표준화·동의·비식별 수집을 거쳐 공사비 참고지표와 분석 연구를 추진한다.
- T: 실제 배포·코드·검증 자료로 실행력을 설명한다. 미확인 매출·협업·연구 성과를 만들지 않는다.

플랫폼 적합성은 높고 초기창업·신뢰거래·소비자보호·건설테크·LBS는 실증과 검토를 전제로 가능하다. AI/R&D·딥테크·오픈이노베이션의 현재 성과 근거는 부족하다. 사업 자격·선정·법적 적합성 보장이 아니다.
