## 12. PSST 초안(사실·근거 우선)

### P — Problem
- 동네 인테리어·집수리는 견적 기준이 업체마다 달라 비교가 어렵고, 계약·공사 과정의 약속이 말과 메신저에 흩어진다.
- 분쟁이 생기면 «언제 무엇을 합의했고 공사가 어디까지 됐는지»를 증명할 기록이 없다.
- 소규모 업체(1인 포함)는 실력을 보여 줄 공식 기록이 없어 광고비에 의존한다.
- (근거 자료 필요: 한국소비자원 인테리어 피해 통계 등 외부 통계 — 인용 출처를 대표/AI 가 확인 후 삽입. 현재 문서에 수치 없음)

### S — Solution
- 공간마켓은 견적 요청 → 입찰·비교 → 현장방문·실측 → 최종견적 → 계약 기록 → 착공·중간·완료 확인 → 후기를 **한 공사 기록**으로 잇는다(GRANT-02 01~12).
- 각 단계에서 버튼을 누를 때만 위치·주소·사진을 남기고(상시 추적 없음), 고객이 단계를 확인한다.
- 업체는 사업자등록증·보험 등 서류를 관리자에게 확인받아야 입찰·계약할 수 있고, 확인된 증빙은 엠블럼으로 보인다.
- 관리자는 한 공사의 위치·사진·대화·계약 기록을 모아 한 장으로 출력할 수 있다.
- 현재 베타: 결제·단계 지급은 PG 협의 뒤 연다(대금은 계약서대로 당사자 간 직접).

### S — Scale-up
- 단기: 보안 보강(GRANT-01) → 결제 오픈 → 실거래 실증 → 앱 스토어 정식 출시(아이폰 등록 준비·안드로이드 비공개 테스트 중).
- 성장 장치(코드 완비): 친구 초대·업체 공개 페이지·명함 QR·간단 견적서·지역별 소식·출석·집 관리 수첩(재방문).
- 데이터 단계: 견적 표준화 → 지역·유형별 공사비 참고 지표 → 신뢰 데이터 모델.
- 수익 구조(코드상 설계): 공간토큰(디지털 이용권 · 앱 안 판매는 스토어 정책상 닫음) · 거래 수수료 설계(fee_config 016·113) — **매출 NO_DATA**.

### T — Team / Execution
- 대표: 인테리어·집수리 교육 과정 수료 예정(2026-10 성요셉목수학교 집수리 과정) · 직접 1인 시공으로 현장 검증 계획(대화 기록).
- 실행 근거: 저장소 SQL 190개 · 자동 테스트 351개 통과 · 빌드 통과 · 수동 E2E 점검 기록(`docs/HANDOFF-2026-09-2x-e2e-*`).
- 부족: 개발 인력 구성·외부 협력 실적·실거래 NO_DATA → 지원서에 «현재 자체 개발, 지원금으로 인력 확충» 으로.
