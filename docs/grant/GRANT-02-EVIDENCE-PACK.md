# 제품 Evidence Pack — 공개 요약

갱신: 2026-09-29. 코드 구현, 공개 서비스 가용성, 인증된 운영 기능 검증은 서로 다른 증거다.

| 제품 영역 | 확보한 근거 | 추가 검증 |
|---|---|---|
| 공개 서비스 | 운영 응답·배포 정보 확인 | 인증된 전체 사용자 흐름 |
| 견적 요청·입찰·비교 | 코드 구현 | 정상 사용자 실증 |
| 업체 서류 검토 | 제출·관리자 검토 흐름 구현 | 운영 접근제어와 실제 검토 과정 |
| 현장·사진·위치 기록 | 버튼 기반 기록 구조 구현 | 작성자·참여자 권한·동의·무결성 |
| 계약 기록·단계 승인 | 기록 및 승인 구조 구현 | 실제 당사자 흐름·보존 체계 |
| 후기 | 계약 후기와 외부 후기 구분 구현 | 운영 회귀 검증 |
| 결제 | 내부 장부·연동 코드 기반 | PG 계약·실결제·정산 실증 |

보안 감사용 데이터 건수를 사용자·거래·매출 실적으로 사용하지 않는다. 실제 사용자 내용이나 상세 보안 근거는 공개 Evidence Pack에 넣지 않는다. 화면 캡처는 실제 상태와 편집 여부를 명시하고 가짜 화면·실적을 만들지 않는다.

## AI/R&D 준비도

PARTIAL. 기록 구조는 있으나 표준화된 입력, 데이터 품질, 동의·비식별 처리, 라벨과 평가 체계의 추가 검증·개발이 필요하다. 학습 데이터 확보 완료나 가격 예측 성능을 주장할 수 없다. 데이터 기능 개선은 보안 수정과 분리된 후속 단계다.
