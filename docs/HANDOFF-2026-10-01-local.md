## 1. ★ 대표 — 아이폰 첫 빌드 (터미널 · 한 번이면 끝)

**이게 되어야 나머지가 의미를 가진다.** 지금 아이폰은 설치 자체가 **불가**다.
`docs/QA-2026-09-30-ios.md` 의 확인 1~6번이 전부 «대기»인 이유가 이것 하나다.

`gonggan-ios` 폴더에서:

```
eas init                                   # 프로젝트 연결 (지금 「no project」 상태)
eas build -p ios --profile production
```

빌드 중 물어보는 것
- 「Push Notifications 설정?」 → **Yes**
- 「새 APNs 키를 만들까?」 → **Yes** (키 파일을 따로 만들 필요 없다)

> 🔒 **APNs 키 파일·비밀번호는 채팅에 붙이지 않는다.** 출력에 섞여 나와도 지우고 보낸다.

빌드가 끝나면 → App Store Connect › TestFlight 에 올라온다 → 폰에 설치 →
`docs/QA-2026-09-30-ios.md` 표 1~6 을 채운다(로그인 유지가 제일 중요하다).

**로그인이 재시작마다 풀리면** 앱 쪽(`gonggan-ios`)을 먼저 본다 —
WebView 가 영구 저장소를 쓰는지(`incognito` 설정 없음) · 앱 시작 때 저장소를 지우는 코드가 없는지.
앱 쪽 원인이 아니면 그때 클라우드 세션이 웹 쪽을 보완한다(규격은 로컬과 맞춘다).

## 2. ★ 로컬 클로드 — 스토어 스크린샷 v2 (지금 **사실이 아닌 문구**가 박혀 있다)

## 3. ★ 대표 — 업체 10곳 (영업 · **코드로 못 메운다**)

지금 업체가 **0곳**이다. 그래서 고객이 앱을 깔고 견적을 요청해도 **아무것도 안 온다.**
설치를 늘려도 첫 화면에서 다 빠져나간다. 점검 점수에서 「깔고 나서 쓸 것」이 **2점**인 이유다.

**10곳이면 충분하다** — 한 지역에서 요청 하나에 견적 3개가 붙으면 비교가 성립한다.

말할 거리(가입 문턱이 낮은 게 강점이다)
- 광고비를 **먼저 안 낸다** — 견적을 요청한 고객에게만 연결된다
- 업체명·연락처·지역·공종만 적으면 **1분 가입 · 승인 대기 없이 바로 입찰**
- 서류를 낼수록 더 큰 공사를 받는다 — **가입만 300만 → 사업자등록 500만 → 시공보험 1,000만 → 보증금 1,500만 미만 → 면허 최대 1억**
- 끝낸 공사가 시공 사례로 남아 다음 고객을 데려온다

> 라운지 바이럴(점검 §2 «이 집은 이렇게 했습니다»)은 **업체가 들어온 뒤**에 만든다.
> 지금 만들면 재료가 없어 **빈 화면만 남는다.**

## 7. 랜딩 문구 — 대표 지적대로 고쳤다 (#914)

대표: 「사업자 등록 업체만 결국에 견적 받을 수밖에 없음」 — **맞다.**
공사비를 받으려면 사업자등록을 할 수밖에 없고, **앱도 그렇게 막아 뒀다**(`contractGate`).

내가 09-30 오전에 이 문장을 **너무 많이 지웠다.** 사실 관계가 틀린 게 아니라
**붙인 자리(견적 → 계약)**가 틀렸던 것인데, 「검증했다」는 말 자체를 빼 버려서
**경쟁 앱과 구분되는 자리를 스스로 버릴 뻔했다.**

| 자리 | 바뀐 문구 |
|---|---|
| 랜딩 히어로 | 같은 조건으로 견적을 받고, **계약은 사업자등록을 확인한 업체와만.** 현장 사진과 진행 단계가 한 자리에 남아 끝까지 안심 |
| 랜딩 여정 02(고르는 날) | 공정·기간·보증을 나란히 놓고 비교합니다. **계약은 사업자등록을 확인한 업체와만 맺습니다** |
| 홈 설명(검색·프리렌더·`llms.txt`) | …**계약은 사업자등록을 확인한 업체와만** 하고, 시공보험·보증금을 어디까지 냈는지도 보입니다 |
| 의뢰인 FAQ | 같은 기준 |
| Service 스키마 | **「사업자등록 확인 업체와 계약」** |

**말만 하고 막는 코드가 없으면 그게 더 나쁘다** — 그래서 `downloadCopy.test.js` 가
문구가 살아 있는지와 **`contractGate` 가 아직 막고 있는지를 같이** 검사한다.
