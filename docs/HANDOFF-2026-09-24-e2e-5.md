## 5. 방법 · 함정 (이번 창에서 새로 배운 것 — 3차 5장·4차 4장에 더해)

- **security definer 함수는 PUBLIC 에 실행 권한이 붙는다.** 1xx 마이그레이션 30여 개에 revoke 가 하나도 없었다. 새 내부 함수(트리거·크론만 부르는 것)는 **만들 때 `revoke execute … from public, anon, authenticated`** 를 같이 쓴다. 부르는 쪽이 전부 definer 인지 먼저 확인(아니면 흐름이 깨진다). 116 의 `company_row_of` 는 그렇게 만들었다.
- **보안 확인은 데이터가 안 바뀌는 호출로**: 없는 ID(`00000000-0000-4000-8000-000000000000`)·변화량 0.
- **결제가 계약 행보다 먼저다**(토스 → 복귀 → escrow insert). 계약 행에서 막으면 «돈은 나갔는데 계약 실패». 결제 관련 문은 **`api/confirm-payment` 의 토스 승인 전**에 둔다(승인 안 하면 매입 안 됨).
- 운영 anon 키·주소는 페이지에서 뽑을 수 있다(공개값): 리소스 목록의 `supabase.co/rest/v1/` 주소 + 앱 스크립트 안의 `eyJ…` 문자열. 운영 스키마 확인·읽기 전용 확인에 쓴다.
- `users` 는 RLS 로 anon 에 빈 목록 → 읽으려면 definer 읽기 함수(115 `user_space_temp` 처럼).
- 업체 한도의 «사업자»는 어디서나 `companies.verified` 하나다(클라이언트 `limitStateOf` · 서버 101 · 지급계획 112 · 결제 문).
- `gh` 는 worktree 소유권 검사에 걸린다 → `export GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=safe.directory GIT_CONFIG_VALUE_0='*'` 뒤에 부른다.
- `gh pr merge` 는 Claude Code 자동 모드가 막는다 → 대표가 GitHub 에서 누른다(또는 `/permissions` 로 허용 규칙).
- `commit-graph` 쓰기 오류가 가끔 뜬다 — 커밋·병합 자체는 된다(무시).
- 파이썬으로 고칠 때 CRLF 파일이 섞여 있다 → `io.open(newline="")` 로 읽고 줄바꿈을 파일에 맞춘다. 새 import 줄을 넣을 때 다른 줄과 줄바꿈이 섞이지 않게.
