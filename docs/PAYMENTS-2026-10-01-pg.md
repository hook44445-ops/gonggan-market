## 1. 포트원 (2026-10-01 회신)

- 공간마켓은 포트원 문서의 **「#16_14 결제금액 임의입력/변동(견적)」 고위험 업종**에 정면으로 해당한다.
  「PG사 입점 심사 시 **까다롭게** 진행될 수 있습니다」
- **포트원에서 임의 심사는 불가** — PG사 리스크팀이 따로 본다
- **파트너정산·지급대행 신규 계약을 받지 않는다.** PG사 것을 써야 한다
- 보증보험 가입 **필수**, 여러 PG 쓰면 **각각** 가입
- 기간: 입점심사 3영업일 → 계약서 1주 → 카드사 심사 2주 ≈ **3~4주**
- 쓸모: **입점 접수 창구로는 그대로 쓸 수 있다.** 콘솔에서 여러 PG에 한 번에 신청
- 결제대행사별 문의처 목록: `help.portone.io/content/information-pg`

## 2. 나이스정보통신 (2026-10-01 회신) — **보류**, 다만 기준선

**보류 사유: 가상계좌 불가.** 조건 자체는 나쁘지 않아 **비교 기준선**으로 남긴다.

| | 나이스 |
|---|---|
| 최대 한도 | **제한 없음** (카드만 카드사 한도) |
| 최소 | 카드 100원 · 계좌이체 200원 · 가상계좌 1원 |
| **가상계좌** | 🔴 **중개플랫폼 이용 불가 업종** (사고 이력 다수) |
| **지급대행** | ✅ 가능 · **별도 입점심사**(이용 불가 판정 가능) |
| **지급대행 비용** | **월 관리비 약 33만원 · 건당 수수료 없음** |
| 카드 수수료 | 독립몰 일반사업자 **3.5%** (VAT 별도) |
| 보증보험 | 중개플랫폼 **필수** · 담보비율은 심사 후 확정 |
| 기간 | 입점심사 4~7영업일 · 계약 총 **3~4주** |

> ⚠️ **용어**: 나이스가 선을 그었다 — 「**에스크로**는 결제 시 이용 가능, **하위 가맹점 지급 시엔 지원하지 않습니다**」
> 우리가 하려는 단계별 분할 지급은 **에스크로가 아니라 「지급대행」**이다. PG 와 말할 때 이 단어를 쓴다(7절).

### 지급대행 비용은 거래가 커질수록 싸진다

| 월 거래액 | 월 33만원의 실질 |
|---|---|
| 3,000만원 | 1.1% |
| **1억원** | **0.33%** |
| 3억원 | 0.11% |

→ 거래 0일 때도 33만원이 나간다. **업체 10곳·첫 거래가 서기 전에는 신청하지 않는다.**

## 2-1. 헥토파이낸셜 (2026-10-01 회신 · 영업관리팀) — **불가**

> 「내부 규정상, **개인사업자 대상 C2C 거래 중개 및 지급대행** 서비스 제공은 불가능합니다.
> (**업력이 낮거나, 매출 자료가 없거나, 기업 신용등급이 낮은 법인** 또한 불가능합니다.)」

- 공간사이는 **개인사업자**(2026-06 개업 · 매출 자료 없음) — 세 조건에 모두 걸린다. **법인으로 바꿔도 «업력·매출» 때문에 지금은 같은 답**일 가능성이 크다.
- 「C2C」는 오해일 수 있다 — 우리 판매자는 **사업자등록이 확인된 업체만**(`contractGate`) = **B2C 중개**. 다만 업력·매출 조건이 따로 있어 고쳐 말해도 결과가 바뀔 가능성은 낮다.
- **배운 것**: 가상계좌 전문사도 **지급대행은 「업체 체급」(업력·매출·신용)으로 막는다.** 남은 곳(KG이니시스·KCP·웰컴)도 같은 기준일 수 있다 → 9절 **C(금액으로 자르기)·«직접 계약으로 실적 먼저»**를 미리 준비한다.
- 물어볼 가치가 있는 것 하나: **«업력·매출 기준이 몇 년·얼마인지»** — 언제 다시 두드릴지 날짜를 정할 수 있다.

## 3. 🔴 가장 큰 문제 — 가상계좌

가상계좌는 **건당 정액**(우리 안내 문구 기준 660원), 카드는 **요율**이다.

| 공사 금액 | 카드 3.5% | 가상계좌 |
|---|---|---|
| 300만원 | 10.5만원 | **660원** |
| 1,000만원 | **35만원** | **660원** |
| 5,000만원 | **175만원** | **660원** |
| 1억원 | **350만원** | **660원** |

코드에도 가상계좌가 「**가장 저렴한 결제수단**」으로 적혀 있다(`src/services/payment/constants.js`).
그리고 지금 설계는 **수수료를 고객이 부담**한다(`FinanceDashboard.jsx` 「고객부담 PG 결제수수료」,
요청서 「가상계좌 이용 시 이용료 660원」).

**1억 공사에 350만원을 고객에게 물리면 아무도 쓰지 않는다.**
대표 10-01: 「고객이 선택할 여지가 있어야 한다」 — 맞다. **가상계좌 없이는 고액 구간이 성립하지 않는다.**

### ⏸ 그래서 보류한 작업

`docs/HANDOFF-2026-09-30-cloud-next-2.md` 2절의 **「가상계좌 입금 웹훅을 api/confirm-payment.js 안에」**
→ **가상계좌가 열리는 PG 가 정해진 뒤에** 한다. 지금 만들면 쓸 데가 없다.

## 6. 부트페이 · 라이트페이 (기존 프루비 때 쓴 것)

| | 자리 | 비슷한 곳 |
|---|---|---|
| **부트페이** | **연동사**(PG를 붙여 주는 쪽) | 포트원 |
| **라이트페이** | **실제 PG** | 나이스 · KG이니시스 |

- 프루비 가맹 때 **약 20만원** 납부. **영수증 수취인**을 봐야 성격이 갈린다 —
  **부트페이**면 공간마켓에도 살려 쓸 수 있고, **라이트페이(PG)**면 버려진다.
- **같은 사업자라도 심사는 다시 받는다.** PG 가맹은 「사업자 + 사이트」 단위라 공간마켓은 **새 MID** 가 나온다.
  > ⚠️ **프루비 MID 로 공간마켓 결제를 받으면 안 된다** — 미등록 상품 판매로 **정산 보류·계약 해지** 사유다.
- **라이트페이로는 공간마켓이 어렵다.** 소액 사업자용 설계로 보인다(가입비 없음·정산한도 200만원까지 보증보험 면제).
  공간마켓은 건당 최대 1억 · 지급대행 필요 · 통신판매중개 — 체급이 다르다.
- **부트페이는 계속 쓸 수 있다.** 부트페이에 물을 것: ① 20만원의 성격과 재부과 여부
  ② 부트페이를 통해 대형 PG 연결 가능 여부 ③ **가상계좌·지급대행이 되는 PG사를 알고 있는지**
  → ③ 이 가장 값어치 있다. PG 를 수십 곳 붙여 본 곳이라 **답을 이미 알고 있을** 수 있다.

> ⚠️ **부트페이로 간다고 벽이 사라지지 않는다.** 부트페이는 연동만 해 주고,
> **심사는 PG사·카드사가** 한다.

## 7. 명칭 — 「에스크로」를 떼고 「지급대행」으로

**「에스크로」는 쓰면 안 되는 말이 됐다.**

- PG 에서 말이 안 통한다 — 나이스: 「에스크로는 **결제 시**, **하위 가맹점 지급 시엔 지원 안 함**」
- 고객에게 더 위험하다 — 전자상거래법상 **결제대금예치(에스크로)는 등록된 예치업자**가 하는 것이다.
  우리는 PG **부가서비스**를 쓰는 것이라, 「에스크로」라고 하면 **법정 보호로 오인**된다(`PAYMENTS_LIVE` 전이라 더 위험).

**새 이름을 만들 필요가 없다 — 이미 쓰고 있다.** `SafePaymentScreen` 설명: 「시공 대금의 **단계별 안전지급** 구조」

| 자리 | 바꿀 것 |
|---|---|
| 고객 브랜드명 | **공간안전결제** — 괄호의 「(에스크로)」만 뗀다 |
| 설명이 필요할 때 | **(단계별 안전지급)** |
| PG·약관·심사 서류 | **지급대행** |
| 코드 내부(`escrow_*` 테이블·변수) | **그대로 둔다** — 바꾸면 위험만 크고 얻는 게 없다 |

## 9. 네 곳 다 가상계좌가 막히면 — 미리 생각해 둘 것

3주 뒤에 알면 늦다.

| 길 | 내용 | 값 |
|---|---|---|
| **A** | **계좌이체 상한(cap)** 있는 곳 | 상한만 있으면 고액이 산다 ← 질문 2번 |
| **B** | **헥토파이낸셜** 등 가상계좌 전문사 | 되면 끝 |
| **C** | **금액으로 자른다** — 중소액만 안전결제, 고액은 중개·기록만 | 고액에서 **안전결제가 사라진다** |
| **D** | 단계별로 쪼개 결제 | 수수료 총액은 **그대로**. 근본 해결 아님 |

**C 가 현실적인 최후 수단**이지만 사업 구조를 바꾸는 결정이다(「1억 공사는 공간마켓이 돈을 안 만진다」).
지금 정할 필요는 없다. 다만 **A·B 가 되는 곳이면 요율이 좀 비싸도 그쪽**이라는 것만 쥐고 비교한다.
