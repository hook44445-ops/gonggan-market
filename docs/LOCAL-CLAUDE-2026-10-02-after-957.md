## 1. 배포 확인 (가장 먼저 · 5분)

Vercel 배포가 끝난 뒤(main `11928f5` 이후):

```bash
UA='Mozilla/5.0 (compatible; Yeti/1.1; +http://naver.me/spd)'
curl -s -A "$UA" https://gongganmarket.com/ | sed 's/<[^>]*>/ /g' | tr -s ' \n' | grep -o '같은 조건으로 받아 나란히 비교[^.]*' | head -1
curl -s -A "$UA" https://gongganmarket.com/safe-payment | tr -d '\n' | grep -o '<h1>[^<]*</h1><p>.\{0,160\}' | head -1
for p in tokens privacy terms refund download; do
  printf "%s " $p; curl -s -A "$UA" https://gongganmarket.com/$p | grep -o '<title>[^<]*</title>'
done
curl -s https://gongganmarket.com/llms.txt | sed -n 1,4p
```

| 볼 것 | 맞으면 |
|---|---|
| 홈 `/` | «같은 조건으로 받아 나란히 비교…» 가 나온다(예전엔 본문 0자) |
| `/safe-payment` | h1 «공간안전결제 (시공대금 단계별 안전지급) — 정식 오픈 후 제공 예정» 바로 다음 문단이 «정식 오픈 후 제공 예정이에요» |
| 나머지 5개 | 제목이 나온다(빈 페이지 아님) · `/tokens` 는 «(정식 오픈 후 판매 예정)» |
| `llms.txt` 3번째 줄 | «> 결제 안내: 공간안전결제는 정식 오픈 후 제공 예정입니다…» |
| 사람 화면(폰·PC 브라우저) | 홈이 평소처럼 — **글자만 잠깐 보이는 깜빡임이 없어야** 한다. 있으면 대표에게 바로 알리고 PR 로 고친다 |

- 하나라도 다르면: 무엇이 다른지 그대로 대표에게 + 클라우드 몫이면 원인만 적어 넘긴다.
- 맞으면 대표에게 «네이버 서치어드바이저 · 구글 Search Console 에서 `/` · `/safe-payment` 수집(색인) 요청» 을 안내한다(콘솔 작업은 대표).

어떻게 고쳤는지(참고): 홈은 빌드 때 `index.html` #root 에 본문을 넣는다(`src/utils/staticHome.js` · `vite.config.js seoStaticHome`). 공개 페이지 글은 `src/content/publicPages.js` 한 곳(화면·봇 같은 데이터) · 봇 rewrite 는 `vercel.json` `/:page(safe-payment|…)`.
