## 4. 방법 · 함정 (이번 창에서 새로 배운 것)

- **운영 DB 직접 조회(anon 키로 표 읽기)는 이 환경의 권한 설정에서 막힌다.** 우회하지 말고 «되돌리는 SQL» 을 만들어 대표에게 드린다: `do $$ … raise exception 'CHECK %', jsonb_pretty(r); end $$;` — 끝의 오류가 전부 되돌리고, 오류 문구 안 JSON 이 결과. 예: `supabase/checks/escrow_plans_check.sql`.
- **점검 요청 설명은 E3 뒤로 「욕실, 주방 — [점검 …」 순서**로 저장된다. 서버 점검 판별은 `like '%[점검%'`(129). 번복 온도 트리거만 고쳤다 — 후기·평가 쪽(109·114)은 `'[점검%'`(앞머리) 그대로라 후기 본문은 「[점검」으로 시작하게 쓸 것.
- **컴포넌트 단독 미리보기**(dev 서버 `gonggan-fix-preview`, 포트 5183): 페이지에서 `import('/node_modules/.vite/deps/react.js')` · `react-dom_client.js`(`createRoot` 는 `.default` 안) · `import('/src/…jsx')` 로 렌더. 파트너 색은 `document.documentElement.setAttribute('data-role','company')`.
- **역할 전환 JS** `window.__switch` 는 새로고침마다 다시 정의(`__btn`·`__sleep` 도). **파트너센터 화면엔 아래 탭(마이)이 없어** 먼저 「←」로 나와야 전환된다.
