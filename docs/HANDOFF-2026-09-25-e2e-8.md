- **운영 DB 에 `escrow_get_or_create` 함수가 없다**(마이그레이션엔 있음). 앱은 폴백(`createEscrowRecord`: `transaction_status 'CONTRACTED'`, `status 'deposited'`, `step1_deposited_at`)으로 계약을 만든다. 계획(`stage_plan`)은 트리거(112)가 채운다.
- **`bids.company_id` 는 업체 주인 사용자 ID 인 경우가 있다**(테스트업체 입찰 = 대표 users.id). 반면 `project_checkpoint_save`(GPS·사진 기록)는 `companies.id` 로 비교한다(`requests.selected_company_id` · `escrow_payments.company_id` · 선택 입찰). 점검 공사를 SQL 로 만들면 `selected_company_id` 를 **업체 ID**(`03438ba2-…`)로 넣어야 한다 — 아니면 `NOT_PROJECT_COMPANY`.
- **점검 공사 만들기**: `supabase/checks/photo_flow_demo.sql`(테스트업체가 입찰한 최근 「[점검」 요청을 본떠 요청·입찰(선택됨)·계약·지급 4줄) + `selected_company_id` 고치기(2장 대화 참고). 설명이 「[점검」으로 시작해 온도·성장 트리거(109·114 `'[점검%'`)에서 빠진다.
- **역할 바꾸기(내부 브라우저, 토큰 없을 때)**: 계정 고르기는 관리자로 고정되므로, 기기 저장값을 바꾼다 —
  ```js
  // 먼저 관리자 값 보관: localStorage.setItem('gonggan_admin_backup', localStorage.getItem('gonggan_user'))
  const u=JSON.parse(localStorage.getItem('gonggan_admin_backup'));
  const co=JSON.parse(localStorage.getItem('gonggan_known_users')).find(x=>x.role==='company');
  localStorage.setItem('gonggan_user', JSON.stringify({...u, role:'company', activeRole:'company', ownerId: co.ownerId ?? u.id, name: co.name}));  // 의뢰인은 role/activeRole 'consumer'
  localStorage.setItem('gonggan_last_role','company'); location.href='/';
  // 끝나면 gonggan_user 를 backup 으로 되돌리고 last_role 'admin'
  ```
  **`role` 과 `activeRole` 둘 다** 바꿔야 한다(activeRole 이 admin 이면 관리자 화면에 「접근 권한 없음」으로 갇힌다). 관리자 화면의 「홈으로」는 관리자에겐 다시 관리자 화면으로 돌아온다(MainApp `screen==="home" && activeRole==="admin"`).
- **사진 올리기(내부 브라우저)**: 파일 창을 못 여니 JS 로 — 사이트 그림을 canvas 로 PNG 로 만들어 `new File([...], '이름.png')` → `DataTransfer` 로 `input[type=file]` 에 넣고 `change` 이벤트. GPS 창은 위치 권한을 켜지 말고 «사유 입력 후 진행»(사유: 「점검 N차 — 사무실에서 하는 과정 점검(현장 아님)」).
- `window.confirm` 은 내부 브라우저에서 바로 닫힌다 → `window.confirm=()=>true` 로 잠깐 바꾼다(7차와 같음). 고객 홈에서 좌표 클릭은 카드 위치가 바뀌어 «무료 견적» 동의 창을 연 적이 있다 — **동의 체크는 대표 몫, 누르지 말고 «취소»**. 카드는 글자로 찾아 누를 것.
- 인라인 그림(show_widget): SVG `<use href="#…">` 는 안 그려진다 → 후보마다 SVG 를 통째로. 로컬 HTML 은 브라우저 pane 에 `file:///…` 로 열면 «정적 스냅샷»으로 대표에게 보인다.
