## 5. 방법 · 함정 (8차 뒤 새로 배운 것)

- **Claude in Chrome 확장은 이 세션에서 끝내 연결되지 않았다**(5번 시도, 「승인했다」 뒤에도). 양방향 점검은 **대표가 크롬에서 두 번째 계정(타일러)을 직접 조작 + Claude 는 내부 브라우저에서 김태웅**으로 했다. 두 브라우저는 저장소가 따로라 동시에 로그인된다.
- **김태웅의 세 역할은 한 사용자**(`9e8b3138…`) — 역할끼리 대화 신청하면 `SELF_REQUEST`. 사람 대 사람 점검엔 번호가 다른 계정이 필요하다.
- **앱 화면의 토큰 잔액을 믿지 말 것**(134 전) — 직접 표 읽기가 막혀 기본값 20. 진짜 값은 대표 SQL(`space_tokens` · `space_token_logs`)로.
- **운영 DB 직접 조회는 여전히 막힌다** — 대표 SQL. SQL Editor 에 **이전 결과 표(`| … |`)가 같이 붙으면 문법 오류**가 난다(09-26 한 번) → 편집기를 비우고 SQL 만.
- **Windows bash heredoc 에 한국어·따옴표·정규식이 많으면 깨진다**(`unexpected EOF`) → 파이썬 스크립트를 **Write 로 스크래치 폴더에 파일로** 쓰고 실행.
- **내부 브라우저 패널이 대표 화면에서 숨겨질 때가 있다** — Claude 가 펼칠 도구가 없다(`show_pane` 목록에 브라우저 없음). 대표가 앱에서 펼쳐야 보인다. 탭이 다른 창 개발 서버(`localhost:5180`)로 바뀌어 있던 적도 있다 → 매번 `tabs_context` 로 확인.
- **미리보기 서버**: 5183·5187 은 다른 창이 쓰는 중일 수 있다 — 5187 이 같은 worktree 를 띄우고 있어 **읽기로만** 썼다(`localhost:5187`). 컴포넌트 단독 렌더(7차 4장).
- **`Icon` 은 `./common` 에서 가져온다**(`import { TempBadge, Icon } from "./common"`) — Vite 빌드는 import 누락을 못 잡는다(실행 중에 터진다).
- **라운지 AI 글 형식**: `**한 줄 답**: …` · `## 소제목` · `## 자주 묻는 질문` + `### 질문\n답` · 마지막 줄 내부 링크 문장. `seoOutline()` 은 FAQ 답을 **빈 줄에서 끊는다**.
- 알림 새 종류를 만들면 **`src/utils/notify.js`(아이콘·등급)와 `api/push/enqueue.js`(푸시 채널) 둘 다** 등록해야 즉시 푸시된다.
