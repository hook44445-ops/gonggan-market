## 1. 🔴 먼저 — 배포 검증 (원격에서 못 함)

#714·#715 는 **라이브 확인을 못 했다.** 배포 후 아래를 돌려서 결과를 대표께 보고할 것.

```bash
# ① www → apex 308 (Vercel 설정은 대표가 09-24 에 완료했다고 확인)
curl -sI https://www.gongganmarket.com/ | head -3
#    기대: HTTP/2 308 + location: https://gongganmarket.com/

# ② canonical 이 항상 apex 인가 (www 로 요청해도)
curl -s -A "Googlebot" https://www.gongganmarket.com/ | grep -o 'rel="canonical"[^>]*'
#    기대: rel="canonical" href="https://gongganmarket.com/"

# ③ 봇 프리렌더 (네이버 Yeti)
curl -s -A "Mozilla/5.0 (compatible; Yeti/1.1; +http://naver.me/spd)" \
     https://gongganmarket.com/ | grep -c "<h1>"
#    기대: 1 이상. 0 이면 rewrite 가 섀도잉된 것 → docs/SEO_AEO_GEO.md §3

# ④ 서치콘솔 URL 검사와 Googlebot 이 같은 문서를 보는가
curl -s -A "Mozilla/5.0 (compatible; Google-InspectionTool/1.0)" \
     https://gongganmarket.com/ | grep -c "<h1>"
#    기대: ③ 과 같은 값

# ⑤ 동적 robots / sitemap / llms
curl -s https://gongganmarket.com/robots.txt   | grep GPTBot
curl -s https://gongganmarket.com/sitemap.xml  | grep -c "<url>"   # 6 보다 커야 함
curl -s https://gongganmarket.com/llms.txt     | head -5

# ⑥ 사람은 SPA 그대로인가 (0 이어야 정상)
curl -s -A "Mozilla/5.0 (iPhone; CPU iPhone OS 17_0)" \
     https://gongganmarket.com/ | grep -c "<h1>"
```

> **⚠️ `public/` 에 `robots.txt` · `sitemap.xml` · `llms.txt` 를 만들면 안 된다.**
> Vercel 은 rewrites 를 파일시스템 확인 **뒤**에 적용하므로 정적 파일이 있으면
> `/api/robots` · `/api/sitemap` 이 영영 호출되지 않는다. 실제로 그 상태였고 #712 이전에 고쳤다.
