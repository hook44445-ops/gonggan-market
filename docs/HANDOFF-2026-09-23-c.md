## 5. 이 세션에서 배운 함정

- **Play Console 탭이 백그라운드면 레이아웃이 멈춘다** — `getBoundingClientRect()` 가 전부 0 이라 클릭·드래그가 안 먹는다. `/json/activate/<targetId>` 로 탭을 앞으로 보낸 뒤에야 좌표가 잡힌다.
- **파일 업로드는 CDP 로 안 된다**(위 5가지 방법 전부 실패). 선택창은 대표 손이 필요하다.
- 드래그 정렬은 **Input.dispatchMouseEvent 로 천천히**(22스텝, 45ms) 움직여야 CDK 가 인식한다.
- 스크린샷을 한 번에 여러 장 올리면 **업로드 완료 순서대로 섞인다** — 올린 뒤 순서를 반드시 확인한다.
