# P. 문제 인식 (Problem)

## 1-1. 왜 지금 이 문제인가

인테리어 계약은 **대부분의 국민이 평생 몇 번 안 하는, 그런데 금액은 가장 큰 거래**다.
처음 해보는 사람이 수백만 원에서 수천만 원을 집행한다. 그래서 세 번 무너진다.

**첫째, 비교가 불가능하다.**
업체마다 견적서 양식이 다르다. A업체는 «주방 일괄 800만원», B업체는 «싱크대·상판·타일·철거»로 나눠 적는다.
숫자가 달라도 **무엇이 포함되고 빠졌는지를 알 수 없으니 비교가 성립하지 않는다.**
소비자는 결국 금액만 보고 고른다. 가장 싼 견적이 가장 많이 빠진 견적일 때가 많다.

**둘째, 공사 중에 깜깜하다.**
계약하고 나면 현장은 닫힌다. 오늘 무엇을 했는지, 어디까지 왔는지 물어보려면 전화를 걸어야 하고,
자주 물으면 실례가 될까 망설인다. **정보 비대칭이 가장 심한 구간이 가장 돈이 많이 나가는 구간이다.**

**셋째, 끝나고 나서 말이 갈린다.**
«그때 그렇게 말했잖아요»가 시작된다. 계약서에 없고, 카톡은 흩어졌고, 사진은 각자 폰에 있다.
분쟁이 나도 **기록이 없어서** 누가 맞는지 가릴 수 없다. 소액이라 소송도 못 간다.

> 이 세 가지는 새로운 발견이 아니다. **누구나 겪었고, 아무도 안 고쳤다.**
> 고치지 않은 이유는 기술이 없어서가 아니라, **기록을 남기면 불리해지는 쪽이 공급자**이기 때문이다.

## 1-2. 기존 해법이 못 한 것

| 방식 | 하는 것 | 멈추는 지점 |
|---|---|---|
| 지역 커뮤니티·지인 소개 | 업체 이름을 알려준다 | 검증 없음 · 비교 없음 · 기록 없음 |
| 견적 중개 앱 | 업체를 연결한다 | **연결까지만.** 계약 이후는 플랫폼 밖 |
| 종합 인테리어 브랜드 | 전 과정을 책임진다 | 단가가 높고 소규모·부분시공을 안 받음 |

**공통점: 모두 「매칭」에서 끝난다.**
그런데 소비자가 실제로 무서운 구간은 **매칭 이후**다. 계약·시공·정산·분쟁이 전부 거기 있다.

# S. 실현 가능성 (Solution)

> 이 항목이 이 계획서의 핵심이다.
> **아이디어 단계가 아니다. 제품이 이미 운영 중이다.**

## 2-1. 해결 구조 — 「매칭까지」가 아니라 「끝까지」

공간마켓은 인테리어 거래의 **전 과정을 한 화면에 기록으로 남긴다.**

```
요청 → 비교 → 계약 → 시공 → 정산 → 후기
 └── 같은 요청서   └── 같은 조건 견적   └── 단계별 사진·대화가 그날짜에 축적
```

| 단계 | 무엇을 하는가 | 무엇이 남는가 |
|---|---|---|
| **요청** | 공간·범위·예산을 한 번 적는다 | 모든 업체가 **같은 요청서**를 본다 |
| **비교** | 업체가 공정·기간·보증을 적어 보낸다 | 금액만이 아니라 **포함/제외**가 나란히 |
| **계약** | 앱에서 견적서 확인·약관 동의 | 계약 범위(`contract_scopes`)가 문서로 |
| **시공** | 착공·중간·완료 사진 업로드 | `phase_photos` — **그날짜에 붙은 증거** |
| **정산** | 단계 확인 후 지급 | 분할 지급 기록 |
| **후기** | 전·후 사진과 평가 | 다음 고객에게 **증거가 됨** |

## 2-2. 차별화 — 신뢰를 「말」이 아니라 「구조」로

### ① 증빙 계단 (수주 한도 자동 제한)

인테리어 사고의 대부분은 **감당 못 할 공사를 받은 업체**에서 난다.
공간마켓은 업체를 **믿는 대신, 증빙한 만큼만 받게 한다.**

| 업체가 제출한 것 | 공사 1건 최대 |
|---|---|
| 가입만 (휴대폰 인증) | **300만원** |
| + 사업자등록증 (관리자 확인) | **500만원** |
| + 시공보험 (증권 승인) | **1,000만원** |
| + 보증금 → **프리미엄 파트너** | **1,500만원 미만** |
| + 실내건축공사업 등록증 | **최대 1억원** |

- 보증금은 **공사 금액의 10%** (시공보험이 없으면 20% — 누수·화재를 보험이 못 막으니 두 배)
- 이 한도는 **화면 문구가 아니라 서버가 강제**한다 (운영 DB 마이그레이션 101, 2026-09-24 적용 완료)
- 1,500만원 기준은 건설산업기본법 「경미한 공사」 상한으로 알려진 값 — `[법무 확인 필요]`

> **왜 이게 차별화인가.**
> 경쟁 서비스는 업체에게 **광고비**를 받는다. 돈을 많이 낸 업체가 위에 뜬다.
> 공간마켓은 **증빙**을 받는다. 증명한 업체가 더 큰 공사를 받는다.
> **소비자 안전과 업체 성장이 같은 방향을 본다.**

### ② 자발적 승급 구조

가입은 3가지만 적으면 끝난다(업체명·지역·공종). 승인 대기도 없다.
서류도 보증금도 **입구에서 받지 않는다.**

들어온 업체는 곧 이 화면을 본다 — **「이 공사는 사업자등록증을 내면 입찰할 수 있어요.」**
더 큰 공사를 받고 싶다는 **업체 자신의 동기**가 증빙을 끌어올린다.

원칙: **「들어오는 건 쉽게, 안의 시스템은 단단하게.」**

### ③ 기록이 곧 분쟁 해결

계약·채팅·현장 사진·진행 단계가 **한 건에 묶여** 저장된다.
분쟁이 나면 말이 아니라 **기록**으로 확인한다.

> 공간사이는 **통신판매중개자**로서 시공 계약의 당사자가 아니다.
> 강제 환불·품질 감정 기관이 아님을 앱에 명시하고 있다. **할 수 있는 것만 약속한다.**

# S. 성장 전략 (Scale-up)

## 3-1. 고객 획득 — 양면 시장을 순서대로

양면 플랫폼의 함정은 **「닭이 먼저냐 달걀이 먼저냐」**다. 공간마켓은 **공급자 먼저**로 푼다.

### 1단계 — 공급(업체) 확보 · ~3개월

업체에게 주는 제안이 단순하다: **광고비를 먼저 쓰지 않는다.**
가입 1분, 승인 대기 없음, 견적 요청 수신 무료.

| 채널 | 근거 |
|---|---|
| 검색 유입 (`/partner`) | **구글 색인 완료** (2026-09-24 확인) · 네이버 수집 완료 |
| 지역 직접 접촉 | 1차 지역 `[대표 확인]` |
| 업체 커뮤니티 | `[대표 확인]` |

### 2단계 — 수요(의뢰인) 확보 · 3~6개월

**검색 기반 무료 유입**이 1차 채널이다. 이미 구축을 마쳤다:

- 「인테리어 비교견적」 검색어로 제목·설명 정렬
- 봇 프리렌더 — 네이버 Yeti는 JS를 실행하지 않아 SPA가 빈 문서로 보이던 문제 해결
- 구조화 데이터(Organization · WebSite · Service · FAQPage · BreadcrumbList)
- 사이트맵 **328페이지** 구글 제출·수집 성공
- 생성형 답변엔진 대응(`llms.txt`, AI 크롤러 명시 허용) — ChatGPT·Perplexity 인용 대비

> **비용 0원의 획득 채널을 먼저 깔았다.** 광고비를 쓰기 전에 검색이 일하게 만든 것이
> 초기 자본이 적은 1인 창업에서 유일하게 합리적인 순서다.

### 3단계 — 커뮤니티 선순환 · 6개월~

**공간라운지**(커뮤니티)에 공간 이야기가 쌓이고, 그 글이 검색 유입을 만들고,
유입이 견적 요청이 되고, 완료된 공사가 시공 사례로 남아 다음 고객을 데려온다.

## 3-2. 수익 모델

| 구분 | 내용 | 시점 |
|---|---|---|
| **중개 이용료** | 계약이 **성사된 프로젝트에만** 부과 | 에스크로 가동 후 |
| 가입비·광고비·월정액 | **없음** | — |
| 수주 실패 시 비용 | **없음** | — |

- **실패한 업체에게 돈을 받지 않는다**는 원칙이 공급자 신뢰의 핵심이다

### 매출 추정

`[대표 확인]` 아래는 **계산 틀만** 제시한다. 숫자는 근거와 함께 대표가 채워야 한다.

```
월 매출 = 월 계약 건수 × 평균 계약 금액 × 이용료율
```

| 항목 | 1년차 | 2년차 | 3년차 |
|---|---|---|---|
| 입점 업체 | `[대표 확인]` | | |
| 월 계약 건수 | `[대표 확인]` | | |
| 평균 계약 금액 | `[대표 확인]` | | |
| 월 매출 | `[대표 확인]` | | |

> **주의.** 정부지원사업 심사에서 근거 없는 하키스틱 그래프는 감점 요인이다.
> **보수적으로 적고, 가정을 명시**하는 쪽이 낫다.
> 예: «1차 지역 업체 30곳 × 월 1건 × 평균 800만원 × 요율 n%».
