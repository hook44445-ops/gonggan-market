# 민감 서류 비공개 처리 — 남은 한 단계(대표)

2026-09-23. 사업자등록증·대표자 신분증·시공보험증권·계약 증빙이 **공개 주소로 저장**되고 있었다.
주소만 알면 누구나 열 수 있는 상태였다.

## 앱에서 고친 것 (배포 완료)

- 새로 올리는 서류는 공개 주소를 만들지 않고 **「버킷/경로」**만 저장한다 (`uploadDocument`).
- 서류를 볼 때는 **10분짜리 임시 주소(서명 URL)**를 그때그때 만든다 (`signedDocUrl`).
- 예전에 공개 주소로 저장된 값도 주소에서 경로를 꺼내 같은 방식으로 연다 → **버킷을 비공개로 바꿔도 관리자 화면이 계속 열린다.**
- 적용한 곳: 파트너 입점 신청(사업자등록증·보험증권·신분증), 업체 온보딩, 서류함, 현장방문·플랫폼 견적서·계약 변경·에스크로 증빙, 관리자 서류 검토·미리보기.
- 사진(포트폴리오·후기·채팅 사진)은 **그대로 공개**다. 고객에게 보여 주는 것이라 바꾸지 않았다.

## 대표가 한 번 해 주실 것 — Supabase 대시보드

1. https://supabase.com/dashboard → 프로젝트 → **Storage**
2. 버킷 **`documents`** → 오른쪽 ⋯ → **Edit bucket** → **Public bucket 끄기** → 저장
3. 버킷 **`company-documents`** 도 같은 방법으로 끄기
4. 버킷 `photos` · `chat-photos` · 후기 사진 버킷은 **공개 그대로 둔다**

끄고 나면:

- 예전에 유출됐을 수 있는 공개 주소는 **그 즉시 열리지 않는다**.
- 관리자 화면은 서명 주소로 계속 열린다(끈 뒤 한 번 확인해 주세요: 관리자 → 파트너 신청 → 서류 「보기」).

## 확인 방법

관리자에서 서류를 열었을 때 주소가 `/object/sign/…?token=…` 형태면 정상이다.
`/object/public/…` 이 보이면 아직 공개 버킷이다.
