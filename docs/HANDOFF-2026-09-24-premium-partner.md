## 2. 확정된 정책 — 코드의 단일 소스

### 수주 한도(공사 1건) — `src/lib/partnerTier.js` `LIMITS`·`bidLimit` = 서버 `101` 과 같은 숫자
| 업체 | 1건 최대 |
|---|---|
| 사업자 없음 · 가입만 | **300만원** |
| 사업자 없음 + 시공보험 또는 보증금 | **500만원** (그 이상은 사업자 필수, 프리미엄 불가) |
| 사업자등록(관리자 확인) | **500만원** |
| + 시공보험(증권 승인) | **1,000만원** |
| 보험 없이 보증금 **20%** | 보증금 × 5, **1,000만원까지** |
| 사업자 + 보험 + 보증금 **10%** = **프리미엄 파트너** | 보증금 × 10, **1,500만원 미만** |
| + 실내건축공사업 등록증(면허) | 보증금 × 10, **최대 1억원** |

- 보증금 10% = 가장 큰 공사의 계약금. 20%는 보험이 없어 누수·화재를 못 막으니 두 배.
- 1,500만원 = 면허 없이 할 수 있는 실내건축 공사 법정 상한(건설산업기본법 「경미한 공사」)으로 **알려진 값 — 법무 확인 필요**.
- 판단값(근거 약함): 300만원, 보험이 들어가는 지점. 숫자는 `LIMITS` 한 곳 + 101 SQL.

### 신뢰 표시 — 관리자가 확인한 값만
- 사업자 = `companies.verified`(관리자 업체 승인) · 시공보험 = `companies.has_insurance`(보험 증권 승인 때 `adminReviewDocument` 가 맞춤) · 보증금 = 공간보증(068) `ACTIVE` · 면허 = `companies.license_verified`(101 이 칸 만듦, 승인 흐름은 아직 없음)
- **`companies.badge` 는 쓰지 말 것** — 옛 가입 화면이 결제 없이 적던 값.

### 카드 3단 — `CompanyCard.jsx` + `partnerTier()`
기본(증빙 0) / 확인된 업체(1~2) / **프리미엄 파트너(3개 모두)** — 프리미엄은 대표 시공 사진·금테·「PREMIUM PARTNER」 문장.

### 입구
- 가입 = 휴대폰 인증 → 업체명·지역·공종 → **바로 ACTIVE**(안전은 한도가 맡음). 수수료·서류·보증금을 입구에서 받지 않는다.

## 6. 지켜야 할 규칙
- 비밀번호·OTP·인증코드·D-U-N-S·**API 키** 는 Claude 가 입력하지 않는다(대표가 직접).

- 생성 이미지에 가짜 글자 금지 · 예시 업체는 「예시」 표시.
- 베타: 예치·보관·에스크로 약속 금지 · **수수료는 입구에서 말하지 않는다**.

- Vercel Hobby 서버리스 함수 **12개 한도** — 새 `api/*.js` 금지, 기존 함수에 얹는다.

## 7. 함정
- **사용자 생성은 `signup_user_by_phone` RPC 로만** — `upsertUserByPhone` 은 새 사용자에게 42501.
- 브라우저로 보내는 JS 템플릿 리터럴 안에서 `\d` 는 `d` 로 죽는다(`\\d`). 셸 큰따옴표 안 `\\$f` 는 `$f` 가 안 풀린다.
- CDP 클릭이 무시되면 창 크기 밖 좌표(메모리 `cdp-click-window-bounds`). Play Console 파일 업로드는 CDP 불가. ASC 스크린샷은 한 장씩.
- 포트원 공식 문서 주소가 404 로 옮겨짐 — 결과 조회는 `GET https://api.portone.io/identity-verifications/{id}` · `Authorization: PortOne <secret>` · `status === "VERIFIED"` · `verifiedCustomer.{name, phoneNumber, birthDate}`.
- 엠블럼 크기: 28px 에선 구분 안 됨 → 증빙 36px · 레벨 40px. 레벨은 본체 지름을 맞춰(`LV_FIT`) 높은 단계가 더 커 보이게.
