## 0. 목표를 숫자로 — 무엇을 «1등»이라 부를지

«1등»은 스토어 카테고리 순위 같은 바깥 숫자라 우리가 직접 못 본다. **우리가 매주 보는 숫자**를 정하고, 그 숫자를 올리는 일만 한다.

| 목표 | 매주 보는 숫자(어디서) | 뜻 |
|---|---|---|
| 1등 다운로드 | ① 새 가입(관리자 «성장 지표») ② 초대 가입(초대왕 순위판) ③ 업체 페이지 방문(업체 «이번 주 N명») ④ 스토어 설치(App Store Connect · Play Console — 대표) | 링크·QR·카드로 퍼져 들어오는가 |
| 1등 재방문 | ⑤ 폰으로 받는 사람 비율(관리자 «📱 푸시 받는 사람») ⑥ 알림별 읽음률(«🔔») ⑦ 출석 연속(162) ⑧ 내 집 관리 수첩 줄 수 | 다시 올 이유가 폰까지 닿고, 눌리는가 |
| 거래로 이어짐 | ⑨ 요청 수 · 견적 수 · 업체 선택 수(«우리 동네 이번 주» · 성장 지표) | 다운로드·재방문이 실제 공사로 |

**첫 4주 목표는 «기준선 잡기 → 매주 오르기»**다. 지금 값이 없어서 목표 숫자를 지어내지 않는다. 4주 뒤 기준선을 보고 대표가 목표를 정한다.

## 1. 지금 있는 것(이미 만든 바퀴)

**다운로드 바퀴 — «보여 주고 싶은 것 + QR/초대 링크»**
- 고객: 📸 전·후 사진 카드 · 👨‍👩‍👧 견적 비교표(가족에게) · 요청 직후 «가족에게 알리기» · 친구 초대(가입하면 공간토큰 20) · 10월 초대왕(1등 300)
- 업체: ⭐ 후기 카드 · 명함·전단 QR · 간단 견적서 · 전·후 카드 — 모두 **업체 페이지 QR** → 업체 페이지 → «공간마켓에서 견적 받기»
- 입구: `/download`(폰 종류별) · 아이폰 사파리 배너(`VITE_APP_STORE_ID` 뒤) · 라운지 글 공유(초대 코드)

**재방문 바퀴 — «때 맞춰 알려 줄 이유 + 폰까지 닿기»**
- 고객: 하자보수 끝나기 한 달 전 · 내 집 관리 수첩(30초 설정) 시기 알림 · 견적 비교해 보셨나요(172) · 찜한 업체 새 사례(179) · 출석 도장 · 오늘의 집 관리 한 줄 · 우리 동네 이번 주 · 우리 동네 최근 완공 사진
- 업체: 새 요청 즉시(110) · 첫 견적 기회(153) · 고객이 견적 확인(173) · 월요일 우리 동네 새 요청(171) · 월요일 페이지 방문 수(161)
- 라운지: 월요일 지난주 인기 글(174) · 인기 글 즉시(139)
- 폰까지: «🔔 알림 켜기»(고객 요청 직후 · 업체 홈) — **웹·안드로이드만. 아이폰 앱은 아직 안 닿는다.**

### 3-B. 클라우드 Claude (앱 코드 · SQL) — 순서대로

1. **아이폰 푸시 받기**(로컬 규격 뒤): `gonggan:push-token` 수신 → `upsertFcmToken(platform "ios_expo")` · `api/push/dispatch.js` 에서 `ios_expo` 는 Expo Push API 로(서버리스 개수 그대로)
2. **공유 순간 늘리기(G4)** — 각각 «자랑할 만한 순간»에만, 한 번:
   - 견적 3개 이상 도착 → «견적 3개 왔어요 · 가족과 같이 보기»(👨‍👩‍👧 비교표로)
   - 공사 완료 확인 → «📸 전·후 카드 만들기»(완공 사진으로 미리 채움)
   - 업체: 별 5개 후기 받음 → 알림 «⭐ 후기 카드로 만들기»
3. **업체 초대 바퀴(G5)** — 고객이 «우리 동네에 업체가 적어요»를 보면 → «아는 사장님 초대하기»(업체용 초대 링크 `/partner?ref=`) · 업체가 업체를 데려오면 초대왕과 별도로 «동료 초대» 순위(보상은 대표 결정 전까지 문구만)
4. **남 이름 쓰기 닫기(G6)** — 요청·입찰·라운지 글/댓글/좋아요 쓰기를 서버 함수(토큰의 사용자)로 옮김 → SQL 로 INSERT true 닫기(«앱 먼저, SQL 나중» · 180 과 같은 방식)
5. **알림 문구 A/B 아닌 «주간 조정»** — 읽음률 20% 미만 알림은 문구·시각을 바꾼다(5절 루프 결과로만)
6. 새 기능을 더하기 전에 **폰 확인 목록**(`HANDOFF-2026-09-29-security-revisit.md` 4절)에서 대표가 막힌 곳부터 고친다
