## 1. 코드로 먼저 본 것 — «앱을 껐다 켜도 로그인 토큰(localStorage)이 남는가»

| 확인 | 결과 | 근거(`gonggan-ios/App.js`) |
|---|---|---|
| WebView 가 비영구(시크릿) 저장소를 쓰나 | ✅ **아니다** — `incognito` 설정이 없어 기본(영구) `WKWebsiteDataStore` 를 쓴다 | `<WebView …>` 속성에 `incognito` 없음 |
| 앱 시작 때 저장소·쿠키를 지우나 | ✅ **지우는 코드 0** | `clearCache`·`clearHistory`·`CookieManager` 호출 없음 |
| 쿠키 공유 | `sharedCookiesEnabled` · `thirdPartyCookiesEnabled` 켬 | 로그인 유지 목적 |
| 도메인 | `https://gongganmarket.com` 하나에서만 연다(밖은 사파리) | `INTERNAL` 정규식 |

→ 코드상으로는 토큰이 남아야 한다. **iOS가 저장 공간이 부족할 때 WebView 데이터를 지울 수 있는지는 실기기로만 확인된다.**
